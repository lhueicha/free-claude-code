Conexión de Aplicaciones & Clientes Externos

Apunta aplicaciones como ChatGPT Desktop, Hermes Agent, Claude Code CLI o Cursor a tu Enrutador local en http://localhost:8082/v1. El Enrutador traducirá las peticiones y optimizará tus tokens automáticamente.

🤖 Hermes Agent 💬 ChatGPT Desktop ⚡ Claude Code CLI

🤖 Conexión con Hermes Agent

Enchufa Hermes al enrutador en un solo paso.

Hermes utiliza el endpoint estándar de OpenAI provisto por Enrutador en http://localhost:8082/v1:

# Opción 1: Ejecución con el lanzador optimizado
fcc-hermes

# Opción 2: Variable de entorno directa en terminal
$env:OPENAI_BASE_URL="http://localhost:8082/v1"
$env:OPENAI_API_KEY="enrutador-key"
hermes chat -m meta/llama-3.3-70b-instruct

💬 Conexión con ChatGPT Desktop

Apunta ChatGPT Desktop o cualquier cliente OpenAI al Enrutador local.

En la configuración de ChatGPT Desktop o cliente OpenAI:

  • Base URL: http://localhost:8082/v1
  • API Key: enrutador-local (cualquier valor de texto)
  • Endpoint utilizado: POST /v1/chat/completions (soporta streaming SSE)
# Prueba directa desde PowerShell / cURL:
curl -X POST http://localhost:8082/v1/chat/completions `
  -H "Content-Type: application/json" `
  -d '{"model":"claude-3-7-sonnet","messages":[{"role":"user","content":"¡Hola Enrutador!"}]}'
